# GazaPharma Link – Medicine Availability Search Platform

GazaPharma Link is a frontend web application designed to help users search for medicine availability across pharmacies in Gaza. The interface focuses on presenting pharmacy results, stock status, medicine details, and request options in a clear and user-friendly way.

As a Frontend team, we decided to improve the visual design of the interface to make it more professional, clear, and user-friendly.
Our focus was on enhancing the layout, spacing, colors, and component structure while keeping the original functionality and user flow unchanged.

## Project Overview

The original GazaPharma Link interface was improved visually and functionally while keeping the main idea and screen flow unchanged. The updates focused on making the medicine search experience cleaner, more professional, and easier for users to understand.

The overall layout was refined by improving spacing, reducing visual clutter, and organizing the content in a clearer way. The search results were redesigned into modern cards instead of a basic traditional layout, making pharmacy and medicine information easier to scan. Each card presents key details such as pharmacy name, medicine availability, quantity, price, location, distance, and last update in a structured format.

## Main UI Improvements

- Redesigned the search results into professional pharmacy cards.
- Improved the visual hierarchy of pharmacy and medicine information.
- Enhanced the availability status indicators for:
  - Available medicine.
  - Low stock medicine.
  - Unavailable medicine.
- Improved spacing, alignment, and layout consistency.
- Reorganized filters and summary statistics to make the page easier to read.
- Improved action buttons such as:
  - View details and map.
  - Call pharmacy.
  - Request alternative medicine.
- Improved side panels such as:
  - Nearest pharmacies.
  - Alerts.
  - Medicine request section.
- Made the interface visually closer to a real medical dashboard.
- Kept the original flow and main functionality unchanged.

## User Experience Goal

The main goal of the improvements was to make the interface easier to use and more professional. Users can quickly understand which pharmacies have the required medicine, compare availability status, and take action without feeling overwhelmed by the amount of information on the screen.

## Key Features

- Medicine search interface.
- Pharmacy availability results.
- Availability status badges.
- Pharmacy details and map view.
- Medicine request flow for unavailable medicines.
- Professional dashboard-style layout.
- Responsive and clean frontend design.
