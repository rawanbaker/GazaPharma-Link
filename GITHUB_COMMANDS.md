# GitHub Commands

Use these commands inside the project folder:

```bash
git init
git add .
git commit -m "feat(scrum-8): add medicine search results and availability details UI"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

If you are working inside the team repository:

```bash
git checkout -b scrum-8-saja-results-interface
git add .
git commit -m "feat(scrum-8): add medicine search results and availability details UI"
git push origin scrum-8-saja-results-interface
```
